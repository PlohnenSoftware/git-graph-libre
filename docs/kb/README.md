# AI Development Knowledge Base

This knowledge base is the working record for recreating useful Git Graph
features in Git Graph Libre while keeping this repository free of any material
the project cannot license under the AGPL. It is the single source of truth for
maintainers and agents; `AGENTS.md` (which `CLAUDE.md`, `CODEX.md` and
`agents.md` link to) only points here.

**Reading it.** Read this index in full, then every section on the
*always read* list below, then go straight to the sections your task needs. Each
section is one file, small enough to read whole, and every entry links to it by
path. Groups run from most to least important (see "Order of this document"
under Rules), and the three-digit prefixes keep sections in that order on disk
as well.

**Changing it.** Edit the section files, never the list below: it is
generated from each section's `# Title` and the `summary` and `always_read` in
its front matter. After adding, removing, renaming, or moving a section, run
`pnpm run kb:index` to rewrite the list. `pnpm run kb:check` fails while the
list is stale or a file breaks the layout rules, and the test suite runs it.
`pnpm run kb:graph` refreshes the graphify graph with the knowledge base in
it, so a query about code also finds the sections that discuss it.
"Order of this document" under Rules holds those rules.
